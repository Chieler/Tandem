# Gather Implementation Plan

**Goal:** Add one MCP call that dispatches delegated tasks and returns their replies together.

**Architecture:** Reuse `send` and `spawn` dispatch and the existing tmux reply buffers. Register waits before dispatch, collect with one batch deadline, and return JSON text with per-task status.

**Tech Stack:** C11, json-c, tmux, Bash integration tests.
